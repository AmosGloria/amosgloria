## Getting Started

Clone the repository:

```bash
git clone https://github.com/AmosGloria/amosgloria
```

Navigate into the project folder:

```bash
cd amosgloria
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
